## Page order

1. **Sort Into Groups** (subtitle "Sort, Count & Compare") — "Cut out the
   pictures. Paste them into the correct group." Cut-and-paste: Things We Wear
   / Things We Eat.
2. **Sort & Count** — "Look at the pictures. Count each group. Write the
   number." 3×3 mixed collection; three answer panels with large number boxes.
3. **Make a Picture Graph** — "Count each kind. Color one box for each
   picture." 9 mixed school items; 3-column block graph (Pencils/Crayons/
   Erasers), 4 sections per column, colored bottom-up.
4. **Read the Graph** — "Look at the graph. Answer the questions." Completed
   "Fruit Graph" bar graph + 4 simplified questions with answer lines.
5. **Sort & Graph Challenge** — "Sort and count the pictures. Then answer the
   questions." 10 new mixed pictures (no Page 2 repeats); counting table;
   most/same-number questions; "Draw one more food" drawing box.
