# Comparing and Measuring Lengths (Grade 1 Math)

Five printable pages that teach measuring length with equal-sized
paper clips: measuring end to end with no gaps or overlaps,
comparing two lengths with a third object, ordering three objects
by length, and measuring real objects at home.

## What children learn

- A length is a count of same-size units laid end to end.
- Units must touch, with no gaps and no overlaps, and must start
  and end exactly with the object.
- A third object (a comparison strip) can carry a length from one
  object to another, so two objects can be compared without moving
  them together.
- More units means a longer object; fewer units means a shorter one.

## Page by page

1. **Which Measurement Is Right?** Four panels show the same pencil
   measured four ways. Only Panel A is correct: same-size clips,
   touching end to end, starting and ending with the pencil. Panel B
   has a gap, Panel C has an overlap, Panel D mixes clip sizes.
2. **Measure with Paper Clips.** Count the clips for four objects
   and write each count: Ribbon 6, Pencil 4, Crayon 8, Straw 5.
3. **Compare Without Moving.** Worked example: the strip matches
   the ribbon, then the same strip falls short of the rope, so the
   rope is longer. Activity: the belt starts later and ends further
   right than the scarf, yet is shorter; lined up with each object's
   own start, the same strip shows the scarf is longer. Children
   circle the Scarf or Belt panel.
4. **Order Three by Length.** Count the clips (Ribbon A 6, Ribbon B
   3, Ribbon C 5), write each count, then write 1 for the shortest,
   2 for the middle, and 3 for the longest: B 1, C 2, A 3. The
   closing check asks children to tick the true sentence: the
   longest ribbon has the most paper clips.
5. **Measure for Real.** A hands-on page: measure a real pencil,
   spoon, and book with real paper clips that are all the same size,
   placed end to end with no gaps and no overlaps. Record each
   count, then circle the longest object (the one that took the
   most paper clips). Counts vary with the real objects used.

## For parents

- Page 5 needs real paper clips, all the same size. If your clips
  differ in size, the counts will not compare fairly.
- Pages 1 to 4 are paper-and-pencil practice; only Page 5 needs
  physical clips.
