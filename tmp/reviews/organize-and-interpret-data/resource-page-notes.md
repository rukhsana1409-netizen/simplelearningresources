# Organize and Interpret Data (Grade 1 Math)

Five printable pages that move from organizing data to reading
and comparing picture graphs, ending with a real survey.

## What children learn

- Sorting objects into three categories and recording counts with
  tally marks (groups of five: four lines, then one line across).
- Turning a tally table into a picture graph, where one picture
  always means one vote.
- Reading a picture graph: how many in each category, how many
  in all, which category has the most.
- Comparing categories: how many more in one category than in
  another, how many fewer, and how many two categories make
  together.
- Collecting real data with a survey, then graphing it.

## Page by page

1. **Sort and Tally.** A jumble of fruit pictures: 6 apples,
   4 bananas, 5 oranges (15 in all). Children count each kind and
   write the tallies and the number in a Picture / Tally / Number
   table. A worked tally example at the top shows how five is
   written.
2. **Build a Picture Graph.** Votes for favorite pet: Dogs 7,
   Cats 5, Fish 3 (15 votes). Children cut out the animal tokens
   in the cut-out area and paste one token for each vote into the
   matching row of the work area. One token always means one vote.
   Paste slots match the token sizes, including the fish tails
   and cat whiskers.
3. **Read the Graph.** A completed picture graph of favorite
   balls: Red 8, Blue 6, Green 4. Questions: how many red balls
   (8), how many blue balls (6), how many balls in all (18),
   which color has the most (Red), and how many more red balls
   than green balls (4). The last question prepares children for
   Page 4.
4. **Compare the Groups.** A completed picture graph of favorite
   toys: Cars 8, Teddy bears 5, Blocks 6. Fill-in sentences:
   Cars have 3 more than teddy bears; Blocks have 2 fewer than
   cars; Cars and blocks together make 14.
5. **Ask and Graph.** A hands-on survey. The child asks people
   "What is your favorite fruit?" (apple, banana, orange),
   records answers with tallies, writes each count, colors one
   box per person in the graph, then answers: which fruit got the
   most, and how many people did you ask. If two fruits tie for
   the most, both count as correct answers.

## Parent guidance: flexible survey size (Page 5)

Page 5 works with any number of respondents from 1 to 10, so it
suits both home and classroom use. There is no fixed number of
people to ask: a child at home may ask just family members (for
example, 4 people), while a classroom can ask up to 10. The graph
has 10 boxes per row, and any boxes left empty are simply left
blank. The closing question "How many people did you ask?" is
answered by adding up the three counts, so the page stays
meaningful at any survey size, large or small. If only one person
is available, the survey still works: one tally, one colored box,
and a clear most-voted fruit. Ties are accepted: if two fruits
tie for the most votes, the child can write both fruit names,
and that counts as correct.

## Notes for printing

- Page 2 needs scissors and glue or tape for the cut-and-paste
  tokens. Cut along the dashed lines; each token fits exactly
  into one work-area box.
- Page 5 needs no materials beyond a pencil and crayons, plus
  people to ask. It can be finished over more than one sitting
  if the child is still collecting answers.
- There is no separate answer key for this pack. Every answer
  is listed above, and every count, total, and comparison was
  checked internally before review.
